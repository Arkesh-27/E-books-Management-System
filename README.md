# 📚 E-Books Management System

An E-Books Management System developed using **Java Servlets** that provides a simple platform for managing and accessing e-books. This project demonstrates core concepts of Java web development, Servlet programming, JDBC, database connectivity, and CRUD operations.

## 🚀 Features

- 📖 Add new e-books
- ✏️ Update e-book information
- 🗑️ Delete e-books
- 🔍 Search and browse e-books
- 📋 View e-book details
- 🗄️ MySQL database integration
- 🌐 Java Servlet-based web application
- 🎨 Simple and user-friendly interface

## ⚙️ How to Run

### 1. Clone the Repository

    git clone https://github.com/Arkesh-27/E-books-Management-System.git

### 2. Open the Project

Open the project in **Eclipse IDE**.

### 3. Configure Apache Tomcat

- Install Apache Tomcat.
- Add Tomcat Server in Eclipse.
- Configure the project with the Tomcat server.

### 4. Configure MySQL

Create a MySQL database:

    CREATE DATABASE ebooks_management;

Configure the JDBC connection details according to your MySQL username, password, and database configuration.

### 5. Run the Application

- Right-click the project.
- Select **Run As → Run on Server**.
- Select **Apache Tomcat**.
- Start the server.
- Open the application in your browser.
